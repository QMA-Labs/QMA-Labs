## What we build

QMA Labs explores AI products that are useful in the real world: tools that teach, protect privacy, reduce repetitive work, and keep humans in control.

| Project | What it does | Focus |
|---|---|---|
| [**PyCoach**](https://github.com/QMA-Labs/PyCoach) | An offline-first Python coach that explains errors and previews safe fixes | Education · Python · Local AI |
| [**MindMirror AI**](https://github.com/QMA-Labs/MindMirror-AI) | Experiments in reflective and human-centered AI experiences | Self-awareness · UX |
| [**AI Email Security Analyzer**](https://github.com/QMA-Labs/AI-Email-Security-Analyzer) | Practical assistance for understanding suspicious email signals | Security · Automation |

## Principles

- 🔒 **Privacy by default** — local processing whenever practical
- 🧠 **Explain, do not just predict** — users should understand the result
- 🛡️ **Safe automation** — previewable, reversible, confidence-aware actions
- 🌱 **Beginner-friendly design** — powerful tools without unnecessary complexity
- ✅ **Evidence over hype** — tests, documentation, limitations, and reproducible releases

## Current spotlight — PyCoach

PyCoach helps beginners move from *“Python says something is wrong”* to *“I understand why and can fix it.”* It includes a self-contained Windows package, VS Code and Thonny integrations, Persian and English guides, deterministic safe fixes, and a fully browsable open-source codebase.
